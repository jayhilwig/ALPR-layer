# Privacy Policy

ALPR Layer does not collect names, email addresses, account information, browsing history, or other personally identifiable information.

The extension reads the geographic area currently displayed in Google Maps and sends the map viewport coordinates to the DeFlock data service solely to retrieve publicly mapped ALPR camera locations for that area.

These coordinates are not stored by the extension, associated with an identity, sold, or used for advertising or profiling.

The extension stores only local user preferences, such as whether the ALPR overlay and direction cones are enabled. These preferences are stored locally in Chrome using the browser's extension storage.

Camera location data is derived from public OpenStreetMap data and surfaced through the DeFlock data pipeline.

ALPR Layer does not sell or transfer user data for purposes unrelated to the extension's single purpose, and it does not use user data for creditworthiness or lending purposes.

## Third-party services

ALPR Layer interacts with:

- Google Maps, where the overlay is displayed.
- DeFlock's public data service, which is queried using the visible map area to retrieve camera-location data.
