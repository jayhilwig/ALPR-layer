# ALPR Layer for Google Maps™

Chrome extension that overlays publicly mapped ALPR camera locations directly on the Google Maps experience.

## What this repo contains

- The extension package
- Listing copy and supporting docs

## Positioning

ALPR Layer is a lightweight overlay for Google Maps that shows publicly mapped ALPR camera locations and direction metadata without forcing users into a separate website or map app.

## Core experience

- Add ALPR markers directly onto Google Maps
- Show direction cones for cameras with direction metadata
- Let users toggle the layer on or off quickly
- Keep the experience native-feeling and visually restrained

## Data

Camera data is public, OpenStreetMap-derived, and surfaced through the DeFlock data pipeline.

## Brand / naming guidance

- Product name: **ALPR Layer**
- Store title: **ALPR Layer for Google Maps™**
- Use **Flock** descriptively in UI copy or marketing copy only when referring to camera brand/type
